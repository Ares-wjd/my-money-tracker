# 기능 명세서 (v0.3 초안)

> 2단계 "세부 기능 정하기"의 결과물. 확정되면 이 문서를 기준으로 기능을 구현한다.
> **확인 필요** 표시가 있는 항목은 추천안을 기본값으로 적어 두었다.

## 0. 전체 구성

| 탭 | 내용 |
| --- | --- |
| 홈 | 투자 자산 요약 + 월별 추이 그래프 |
| 계좌 | 투자 계좌 → 보유 종목 관리 |
| 목표 | 목적통장 (투자 자산과 완전히 분리) |
| 설정 | 계정, 로그아웃, (API 키 등) |

- 데이터는 Google 계정별로 Firebase Firestore 에 저장한다.
- **투자 자산**과 **목적통장**은 데이터·화면·통계 모두 분리한다. 목적통장은 홈 화면의 합계나 그래프에 들어가지 않는다.
- 통화: 원화(KRW)와 달러(USD)를 지원한다. 합계는 원화로 환산해 표시한다.

## 1. 투자 자산 (홈 / 계좌 탭)

### 1-1. 구조
```
투자 계좌 (예: 키움 국내, 미래에셋 해외, 연금저축)
 ├─ 입출금 기록      → 투자금 계산
 ├─ 보유 종목 (주식 / ETF / 펀드 / 채권, KRW 또는 USD)
 │   ├─ 매수·매도 기록 (날짜, 수량, 단가, 수수료·세금)
 │   └─ 배당 기록 (날짜, 금액)
 └─ 예수금 (계좌 안의 현금)
```

### 1-2. 입력하는 것
| 기록 | 항목 |
| --- | --- |
| 입금 / 출금 | 날짜, 금액 (원화 기준. **확인 필요**: 달러로 입금하면 그날 환율로 원화 환산) |
| 매수 / 매도 | 날짜, 종목, 수량, 단가(종목 통화), 수수료·세금(선택) |
| 배당 | 날짜, 종목, 금액(종목 통화). **확인 필요**: 세후 실수령액 기준 |
| 초기 보유분 | 앱을 처음 쓸 때 이미 가진 종목은 "현재 수량 + 평균단가 + 기준일"로 한 번에 등록 |
| 예수금 보정 | 자동 계산된 예수금이 실제와 다르면 직접 맞춤 |

### 1-3. 계산하는 것
- **투자금** = 입금 합계 − 출금 합계 (원화)
- **예수금** = 투자금 − 매수금액 + 매도금액 + 배당 − 수수료·세금 (자동 계산 + 직접 보정)
- **평균단가**: 이동평균법 (국내 증권사 기본 방식)
- **종목 평가금** = 보유 수량 × 현재가 (달러 종목은 × 환율)
- **계좌 평가금** = 종목 평가금 합계 + 예수금
- **수익금(배당 포함)** = 계좌 평가금 − 투자금
- **수익금(배당 미포함)** = 수익금(배당 포함) − 누적 배당
- **수익률** = 수익금 ÷ 투자금 (배당 포함 / 미포함 두 가지 모두 표시)
- 종목별로도 매수원금, 평가손익, 수익률(배당 포함/미포함)을 표시

### 1-4. 시세 자동 반영
| 자산 | 출처 | 비고 |
| --- | --- | --- |
| 국내 주식 | 공공데이터포털 `금융위원회_주식시세정보` | 무료 공식 API, 날짜별 종가 조회 가능 (다음 영업일 제공) |
| 국내 ETF | 공공데이터포털 `금융위원회_증권상품시세정보` | 국내 ETF 전 종목 |
| 국내 현재가(당일) | 네이버 증권 (비공식) | 보조용. 실패하면 공식 API 의 최근 종가 사용 |
| 해외 주식/ETF | **확인 필요**: Yahoo Finance (비공식, 무료, 날짜별 종가 조회 가능) | |
| 환율 (USD/KRW) | 한국수출입은행 환율 API (무료 공식, 날짜별 조회) | |
| 펀드 | 기준가 직접 입력 | 무료 공식 API 없음 |
| 채권 | 매수금액 + 경과이자 자동 추정, 또는 직접 입력 | 장외채권은 시세 출처 없음 |

- 시세 조회에 실패하면 마지막으로 받은 가격을 쓰고, 가격 옆에 기준일을 표시한다.
- 어떤 종목이든 가격을 직접 입력해 덮어쓸 수 있다.

### 1-5. 월말 잔고 자동 기록
- 매월 마지막 영업일 기준으로 **계좌별 평가금 · 투자금 · 누적 배당**을 기록한다.
  - 평가금 = 그날 보유 수량(매매 기록으로 계산) × 그날 종가 × 그날 환율 + 예수금
- 서버 없이 앱이 처리한다. 앱을 열 때 빠진 월말이 있으면 그 날짜의 종가로 소급 기록한다.
- 홈 화면
  - 투자 자산 총 평가금, 투자금, 수익금·수익률(배당 포함/미포함)
  - **월별 추이 그래프**: 평가금 선과 투자금 선
  - 전월 대비 증감, 계좌별·자산 유형별 비중

## 2. 목적통장 (목표 탭)

### 2-1. 구조
```
목적통장 (예: IT기기금, 지출)  ← 잔액은 가끔 직접 입력, 기대수익률(연 %) 설정
 └─ 목표 여러 개
     ├─ 1회성: 이름, 금액, 날짜          (예: 2028-10-08 노트북 1,000만원)
     └─ 반복:  이름, 금액, 주기(N개월), 다음 날짜 (예: 2년마다 휴대폰 200만원)
```
- 원화만 사용한다. 잔액은 CMA·채권을 합친 현재 금액을 직접 입력하고, 입력 날짜를 표시한다.
- 반복 목표는 날짜가 지나면 다음 날짜(+N개월)로 자동으로 넘어간다. 실제 지출은 사용자가 잔액을 수정해 반영한다.

### 2-2. 잔액 배분 (가까운 목표부터 채우기)
1. 목표를 다음 날짜가 가까운 순서로 정렬한다.
2. 통장 잔액을 앞에서부터 각 목표 금액만큼 채운다. 잔액이 다 떨어지면 그 뒤 목표는 0원이다.
3. **모든 목표를 순서대로 보여준다**: 배분된 금액, 달성률(%), 남은 개월 수, 매달 넣어야 할 금액.

### 2-3. 매달 넣어야 할 금액 (이자 반영)
- 월 이율 r = (1 + 연 기대수익률)^(1/12) − 1, n = 목표일까지 남은 개월 수, A = 배분된 금액, T = 목표 금액
- 매달 납입액 P = (T − A·(1+r)^n) ÷ (((1+r)^n − 1) ÷ r) (0 이하이면 "달성 예상")
- 통장 단위로 이번 달 총 납입액(목표별 P 합계)을 보여준다.

예시 (IT기기금 통장 잔액 50만원, 연 3.5%, 2026년 10월 기준):

| 목표 | 금액 | 날짜 | 배분 | 달성률 | 월 납입액 |
| --- | --- | --- | --- | --- | --- |
| 휴대폰 (2년마다) | 200만원 | 2027-04 (6개월 후) | 50만원 | 25% | 246,776원 |
| 노트북 (1회) | 1,000만원 | 2028-10 (24개월 후) | 0원 | 0% | 403,075원 |

→ 이번 달 IT기기금 통장 총 납입액: 649,851원

## 3. 확인 필요 항목 (추천안을 기본값으로 둠)
1. 해외 시세 출처: Yahoo Finance(비공식). 한국투자증권 계좌가 있으면 공식 KIS Open API 로 국내·해외를 모두 받을 수 있다.
2. 달러 입금 처리: 투자금은 원화 기준이고, 달러 입금은 그날 환율로 환산한다.
3. 배당: 세후 실수령액으로 기록한다.
4. 매매 수수료·세금: 선택 입력.
5. 예수금: 기록으로 자동 계산하고, 실제와 다르면 직접 보정한다.
